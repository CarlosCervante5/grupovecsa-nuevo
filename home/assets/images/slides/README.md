# Estructura de Imágenes para Slides

Esta carpeta contiene la estructura organizada para las imágenes de los slides del home.

## Estructura de Carpetas

```
slides/
├── slide1/          # MINI 3 Puertas E
│   ├── desktop/     # Imagen para desktop
│   └── mobile/      # Imagen para mobile
├── slide2/          # BMW F 900 GS
│   ├── desktop/     # Imagen para desktop
│   └── mobile/      # Imagen para mobile
├── slide3/          # BMW X5 xDrive50e
│   ├── desktop/     # Imagen para desktop
│   └── mobile/      # Imagen para mobile
└── slide4/          # BMW Motorrad GEAR & GARMENT
    ├── desktop/     # Imagen para desktop
    └── mobile/      # Imagen para mobile
```

## Cómo Actualizar Imágenes

### Para actualizar un slide específico:

1. **Slide 1 (MINI 3 Puertas E):**
   - Desktop: Reemplazar `slides/slide1/desktop/MINI_st.jpg`
   - Mobile: Reemplazar `slides/slide1/mobile/mini-m.jpg`

2. **Slide 2 (BMW F 900 GS):**
   - Desktop: Reemplazar `slides/slide2/desktop/MOTO_st.jpg`
   - Mobile: Reemplazar `slides/slide2/mobile/moto-m.jpg`

3. **Slide 3 (BMW X5 xDrive50e):**
   - Desktop: Reemplazar `slides/slide3/desktop/BMW_st.jpg`
   - Mobile: Reemplazar `slides/slide3/mobile/bmw-m.jpg`

4. **Slide 4 (BMW Motorrad GEAR & GARMENT):**
   - Desktop: Reemplazar `slides/slide4/desktop/FONDO_desk.jpg`
   - Mobile: Reemplazar `slides/slide4/mobile/FONDO_mov.png`

### Reglas Importantes:

- **Mantener los nombres de archivo exactos** para que el código funcione
- **Formato recomendado:** JPG para fotos, PNG para imágenes con transparencia
- **Resolución recomendada:** 
  - Desktop: 1920x1080px o superior
  - Mobile: 768x1024px o superior
- **Peso máximo:** 2MB por imagen para optimizar carga

### Ventajas de esta estructura:

✅ **Fácil gestión:** Cada slide tiene su propia carpeta
✅ **Separación clara:** Desktop y mobile están separados
✅ **Actualización simple:** Solo reemplazar la imagen en la carpeta correspondiente
✅ **Organización:** Estructura predecible y escalable
✅ **Mantenimiento:** Fácil identificar qué imagen corresponde a cada slide
